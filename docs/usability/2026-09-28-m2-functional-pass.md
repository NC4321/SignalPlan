# M2 functional pass by the author — 2026-09-28

Part of closing M2 (smart placement), done after the exit gate ([#76](https://github.com/NC4321/SignalPlan/issues/76), D47) merged.

## What was tried

The project's author tried the M2 features themselves:

- locking access points in place (D43);
- "Suggest a spot" for one access point, with the heatmap preview, Apply and Dismiss (D44);
- moving several access points together and "Suggest one more access point" (D45);
- "How many access points do I need?" with the coverage goal menu (D46).

## Result

The author reported that everything seemed good, and no new issues were filed.

## What this doesn't cover

As with the [M1 pass](2026-09-28-functional-pass.md), this was a check by someone who knows the app, not the first-time-user test in the [test script](test-script.md). It shows the features work, but not whether a newcomer finds the optimizer or understands its suggestions. Watching 2–3 first-time users ([#77](https://github.com/NC4321/SignalPlan/issues/77)) moves to M3 and still must happen before any launch post (D39, D48).
